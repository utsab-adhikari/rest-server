Overview

All endpoints live under https://rest.utsab.space/api. Requests and responses are JSON. For POST, PUT, and PATCH, always send the header Content-Type: application/json.

Status Codes

200 OK, 201 Created

The request succeeded. 201 means a new resource was created.

400 Bad Request

The payload failed validation. Check the field types and required keys.

401 Unauthorized

The supplied password did not match the one on record.

404 Not Found

No user exists with that ID.

409 Conflict

A user with that email already exists.

500 Internal Error

Something went wrong on the server. Try again in a moment.

Users

List Users

GET /api/users

Returns every user in the collection. Passwords are stripped from the response.

{
  "success": true,
  "count": 2,
  "users": [
    {
      "_id": "64f1b2c3a...",
      "name": "Jane Doe",
      "email": "jane@example.com"
    }
  ]
}

Create User

POST /api/users
Body Type Description
name Req String Full name of the user.
email Req String Valid email. Must be unique.
password Req String Hashed with bcrypt before storage. 
{
  "success": true,
  "message": "User Created Successfully.",
  "user": {
    "_id": "64f1b2c3a...",
    "name": "Jane Doe",
    "email": "jane@example.com",
    "password": "$2b$10$hashed..."
  }
}

Update User (Full)

PUT /api/users/:id

Replaces both the name and email. The current password is required to authorize the change.

Parameter Location Description
id Req Path MongoDB ObjectId of the user.
name Req Body New name.
email Req Body New email.
password Req Body Current password to authorize the update.

Update User (Partial)

PATCH /api/users/:id

Updates only the fields you send. The current password is still required.

Parameter Location Description
id Req Path MongoDB ObjectId of the user.
name Opt Body New name. Skipped if omitted.
email Opt Body New email. Skipped if omitted.
password Req Body Current password to authorize the update.

Delete User

DELETE /api/users/:id

Removes the user. The current password is required to authorize the deletion.

Parameter Location Description
id Req Path MongoDB ObjectId of the user.
password Req Body Current password to authorize the deletion. 
{
  "success": true,
  "message": "User Deleted Successfully"
}

System Metrics

GET /api/system/metrics

Returns OS level telemetry such as CPU usage, memory, and process uptime. Useful for health checks and uptime monitors.
