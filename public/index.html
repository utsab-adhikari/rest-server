Backend · REST API

REST Server

v1.0.0  |  Basic CRUD

A small and reliable REST API backend built with Express, TypeScript, and MongoDB. It handles user accounts and exposes basic system metrics for monitoring.

The code is organized so each part does one job. Routes handle HTTP, controllers handle logic, and schemas keep the data clean. Passwords are hashed, requests are rate limited, and every response comes back as JSON.

Read the Docs Try the UI
What it does

Built for the basics, done right.

No bloated frameworks. Just the essentials you need to ship a working backend.

Clean data in, clean data out

Every request is checked against a schema before it reaches the database. Bad input gets rejected early with a clear error message.

Know what is happening

A single endpoint reports CPU usage, memory, and process uptime. Handy for uptime monitors and health checks.

Sensible security defaults

Helmet headers, CORS, request size limits, and rate limiting are all wired up out of the box.

What you can call

Users

Create, read, update, and delete user accounts.

GET /api/users
POST /api/users
PUT /api/users/:id
PATCH /api/users/:id
DEL /api/users/:id

System

Hardware metrics and current server status.

GET /api/system/metrics
